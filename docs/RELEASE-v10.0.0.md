# v10.0.0 — Signature Journeys Edition

Prepared 2 August 2026 from the v9.9.0 International Edition production
baseline.

## Release scope

- Homepage: one integrated Featured Journey beneath the established editorial
  structure without changing the approved hero.
- Signature Journeys: a new collection route and flagship journey card.
- Masai Mara Signature Safari: a seven-day journey framework, scope language,
  responsive presentation and tailored enquiry CTA.
- Journal flow: the Kenya article leads to the flagship journey and the Mara
  destination exposes both editorial and journey routes.
- Enquiry: `Tailor This Journey` preselects Leisure Travel and prefills the
  journey name, destination and opening message.

## Deployment status

Approved for Verpex deployment. The three locally created Signature Journey
images are interim launch media. Replace them in a future content release when
approved partner media-kit assets become available, then repeat visual,
metadata, accessibility and image-rights review.
